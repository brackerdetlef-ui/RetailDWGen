# Contributing

Thank you for your interest in RetailDWGen.

Contributions of all kinds are welcome, including bug reports, documentation improvements, suggestions, and code contributions.

## Reporting Issues

When reporting an issue, please include as much information as possible, for example:

* Operating system
* Python version
* Steps to reproduce the problem
* Expected behavior
* Actual behavior
* Complete error message, if available

## Pull Requests

Before submitting a pull request, please ensure that:

* the code is readable and well documented;
* existing functionality is not broken;
* changes follow the current project structure;
* new functionality has been tested.

## Code Style

Please keep the implementation simple, modular and easy to understand.

The goal of RetailDWGen is to provide realistic test data for retail and data warehouse environments while keeping the project easy to maintain.

Thank you for helping to improve RetailDWGen.
