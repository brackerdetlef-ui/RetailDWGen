# Contribuer

Merci de votre intérêt pour RetailDWGen.

Toutes les contributions sont les bienvenues, qu'il s'agisse de rapports de bogues, d'améliorations de la documentation, de suggestions ou de contributions au code.

## Signaler un problème

Merci d'indiquer autant d'informations que possible :

* Système d'exploitation
* Version de Python
* Étapes permettant de reproduire le problème
* Comportement attendu
* Comportement observé
* Message d'erreur complet, si disponible

## Pull Requests

Avant de soumettre une Pull Request, veuillez vérifier que :

* le code est clair et bien documenté ;
* les fonctionnalités existantes continuent de fonctionner correctement ;
* la structure actuelle du projet est respectée ;
* les nouvelles fonctionnalités ont été testées.

## Style de développement

Merci de privilégier un code simple, modulaire et facile à comprendre.

L'objectif de RetailDWGen est de générer des données de test réalistes pour les entreprises du commerce et les projets de Data Warehouse, tout en conservant un projet simple à maintenir.

Merci de votre contribution à RetailDWGen.
