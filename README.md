# RetailDWGen

Generator für realistische Testdaten eines Handelsunternehmens.

## Voraussetzungen

- Python 3.10.12
- Linux Mint

## Installation

```bash
python3 -m venv .venv

source .venv/bin/activate

python3 -m pip install -r requirements.txt
```

## Start

```bash
python generate.py
```

Die erzeugten CSV-Dateien befinden sich anschließend im Ordner

```
output/
```
