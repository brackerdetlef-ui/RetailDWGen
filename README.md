# RetailDWGen

Generator für realistische Testdaten eines Handelsunternehmens.

## Voraussetzungen

- Python 3.10.12
- PostgreSQL (später)
- dbt (später)

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

## Start

```bash
python generate.py
```
