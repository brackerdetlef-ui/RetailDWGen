# Contribuir

Gracias por tu interés en RetailDWGen.

Se agradecen todo tipo de contribuciones, incluyendo informes de errores, mejoras en la documentación, sugerencias y aportaciones de código.

## Informar de errores

Al informar de un problema, incluye siempre que sea posible:

* Sistema operativo
* Versión de Python
* Pasos para reproducir el problema
* Comportamiento esperado
* Comportamiento observado
* Mensaje de error completo, si existe

## Pull Requests

Antes de enviar un Pull Request, asegúrate de que:

* el código sea claro y esté documentado;
* la funcionalidad existente continúe funcionando correctamente;
* se respete la estructura actual del proyecto;
* las nuevas funciones hayan sido probadas.

## Estilo de programación

Procura mantener el código sencillo, modular y fácil de comprender.

El objetivo de RetailDWGen es generar datos de prueba realistas para empresas del sector comercial y proyectos de Data Warehouse, manteniendo un proyecto fácil de mantener.

Gracias por contribuir a RetailDWGen.
